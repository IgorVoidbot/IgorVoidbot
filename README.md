## Projetos em destaque

### [E-commerce API — Java / Spring Boot](https://github.com/IgorVoidbot/ecommerce-api)

API REST para gerenciamento de usuários, produtos, carrinho e pedidos.

- Autenticação JWT e autorização por perfis com Spring Security.
- Regras de estoque e checkout transacional, incluindo cancelamento e devolução de itens.
- PostgreSQL, migrations com Flyway, documentação OpenAPI/Swagger e Docker Compose.
- Testes automatizados com JUnit, Mockito e MockMvc, além de pipeline de CI com GitHub Actions.

**Stack:** Java 21 · Spring Boot · PostgreSQL · JPA · Spring Security · Docker

### [Finanpy — Python / Django](https://github.com/IgorVoidbot/finanpy)

Aplicação de finanças pessoais para gerenciamento de contas, categorias e transações.

- Atualização de saldos e validações de movimentações financeiras.
- Autenticação e isolamento de dados por usuário.
- Testes automatizados com Pytest e módulo opcional de análise financeira por IA.

**Stack:** Python · Django · SQLite · Pytest · Docker

### [Trevo4Folhas — projeto em desenvolvimento](https://github.com/IgorVoidbot/trevo4folhas)

Aplicação web para registro de pré-bilhetes esportivos e gestão administrativa.

- Modelagem de dados e migrations para PostgreSQL.
- Implementação de regras transacionais, idempotência e tratamento de conflitos na emissão.
- Uso de Spring Boot, Flyway e testes de integração.

**Stack:** Java 17 · Spring Boot · PostgreSQL · Flyway · Testcontainers
